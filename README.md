**Features**
**1. Customer-Facing Features:**
   - Homepage: Browse restaurants, food categories, and featured dishes.
   - **User Management**: Register, log in, update profile information, and change passwords.
   - **Food Browsing**: Search and filter dishes by category or restaurant, view details, and browse paginated results.
   - **Shopping Cart**: Add dishes, update quantities, and review items before checkout.
   - **Order Placement**: Place orders with a delivery address, payment method, and optional voucher.
   - **Order Tracking**: View order history and cancel orders that are still pending.
   - **Reviews and Favorites**: Rate and comment on dishes, and save favorite dishes.
**2. Admin-Facing Features:**
   - **User Management**: View customer accounts and lock or unlock accounts.
   - **Order Management**: View and filter orders, inspect order details, and update order statuses.
   - **Food Management**: Add and edit dishes, and stop or resume sales. Dishes are deactivated using the IsActive flag rather than permanently deleted.
   - **Voucher Management**: Add, edit, enable, or disable discount vouchers.
   - **Dashboard**: View user, order, and revenue statistics, popular dishes, and recent price changes.

## Technologies Used
- **Framework:** ASP.NET Framework
- **ORM:** Entity Framework (Database First)
- **Language:** C#
- **Database:** In-memory database
- **Frontend:** Razor Views, HTML, CSS, JavaScript
- **Backend:** LINQ and Entity Framework
